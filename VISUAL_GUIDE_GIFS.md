# 🎬 GUIDE VISUEL - GIFs Animés Messenger (ÉTAPE PAR ÉTAPE)

## ÉTAPE 1️⃣ : REBUILD LE PROJET (30-60 secondes)

```
┌─ IntelliJ Menu ──────────────────────────────┐
│                                               │
│  Build ↓                                      │
│  ├─ ✅ Rebuild Project    ← CLIQUEZ ICI     │
│  ├─ Make Project                              │
│  └─ ...                                       │
│                                               │
└───────────────────────────────────────────────┘

OU simplement : Ctrl + Shift + F9

⏳ EN BAS, vous verrez :
"Building.... Please wait"
"Build completed successfully" ← ATTENDEZ CETTE MESSAGE
```

---

## ÉTAPE 2️⃣ : LANCER L'APPLICATION

```
┌─ Project Explorer ─────────────────────────────┐
│                                                 │
│  src/main/java/                                │
│  ├─ ChatConsoleApp.java  ← CLIC DROIT        │

│                                                 │
└─────────────────────────────────────────────────┘

OU simplement :

```

## ÉTAPE 3️⃣ : UTILISER LES GIFs

### 3a. Sélectionner un groupe

```
┌─ MESSAGERIE ─────────────────────────────────┐
│  🔍 Rechercher un groupe                      │
│  ├─ priveeee                                  │
│  ├─ aziiiiiizzz  ← CLIQUEZ ICI               │
│  ├─ weal...                                   │
│                                                │
│  (Nom du groupe s'affiche en haut)            │
└──────────────────────────────────────────────┘
```

### 3b. Ouvrir le sélecteur de GIFs

```
┌─────────────────────────────────────────────────┐
│  Chat                                            │
│  [😊] [🎁] [🗑] [📍] [🎤]  ← CLIQUEZ SUR 🎁  │
│                                                  │
│  "Tapez votre message..."                       │
└─────────────────────────────────────────────────┘
```

### 3c. La fenêtre GIFs s'ouvre

```
┌──────────────────────────────────────────────────────────┐
│ GIFs - Messenger Style                                 X │
├──────────────────────────────────────────────────────────┤
│                                                            │
│ ┌──────────────┐              ┌─────────────────────┐   │
│ │🔍 Chercher   │              │Sélectionnez un GIF  │   │
│ │des GIFs...   │              │                     │   │
│ └──────────────┘              │                     │   │
│                               │ [APERÇU ICI]       │   │
│ ┌──────┐ ┌──────┐             │                     │   │
│ │ GIF1 │ │ GIF2 │             │                     │   │
│ └──────┘ └──────┘             └─────────────────────┘   │
│ ┌──────┐ ┌──────┐             ✓ Prêt à envoyer           │
│ │ GIF3 │ │ GIF4 │                                        │
│ └──────┘ └──────┘             [Envoyer GIF] [Annuler]   │
│                                                            │
└──────────────────────────────────────────────────────────┘
```

### 3d. Rechercher des GIFs

```
1. Tapez dans la barre (ex: "cat")
2. Appuyez sur Entrée OU attendez 2 secondes
3. Les GIFs catégories s'affichent à gauche

┌─ Gauche ─────────┐
│ 🔍 cat            │
│ "15 GIFs trouvés" │
│                   │
│ ┌─────┐ ┌─────┐  │
│ │ 🐱  │ │ 😺  │  │
│ └─────┘ └─────┘  │
│ ┌─────┐ ┌─────┐  │
│ │ 😻  │ │ 😽  │  │
│ └─────┘ └─────┘  │
└───────────────────┘
```

### 3e. Sélectionner un GIF

```
┌─ Gauche ─────────┐    ┌─ Droite ──────────────┐
│ ┌─────┐ ┌─────┐  │    │ GIF Chat qui danse   │
│ │ 🐱  │ │ 😺  │  │    │                      │
│ └─────┘ └─────┘  │    │  [GIF ANIMÉ ICI] 🎬  │
│ ┌─────┐ ┌─────┐  │    │  ← TOURNE EN BOUCLE  │
│ │ 😻  │ │ 😽  │  │    │                      │
│ └─────┘ └─────┘  │    │ ✓ Prêt à envoyer     │
│                   │    │                      │
│ (CLIQUEZ UN GIF)  │    └────────────────────────┘
└───────────────────┘
```

### 3f. Envoyer le GIF

```
┌─────────────────────────────────────────────┐
│                                              │
│          [Envoyer GIF] [Annuler]            │
│            ↑ CLIQUEZ ICI                    │
│                                              │
└─────────────────────────────────────────────┘

⏳ ATTENDRE...
- Téléchargement du GIF (1-3 sec)
- Enregistrement en base
- Chargement des messages
```
