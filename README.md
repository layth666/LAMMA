PI_DEV – Plateforme de Gestion d'Événements
Description

PI_DEV est une application desktop développée en Java (JavaFX) qui permet de gérer des événements et d'interagir avec différents modules liés à l'organisation d'activités.
Le projet a été réalisé dans le cadre d'un projet académique en développement logiciel, en utilisant une architecture structurée et plusieurs services pour gérer les fonctionnalités principales.

L'application permet aux utilisateurs et aux administrateurs de gérer des événements, participer à des activités, communiquer avec d'autres participants et accéder à plusieurs services liés aux événements.




Technologies utilisées

Java

JavaFX

FXML & Scene Builder

MySQL

Maven

Git & GitHub
