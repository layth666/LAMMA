# 🚀 GUIDE RAPIDE - Démarrage

## Étape 1 : Ouvrir le projet

```
1. Ouvrir IntelliJ IDEA
2. File → Open → Sélectionner le dossier "Gestion_Equipements"
3. Attendre que Maven charge les dépendances (quelques minutes)
```

## Étape 2 : Compiler le projet

```
1. Build → Rebuild Project
2. Ou : Ctrl + Shift + F9
3. Attendre la fin du build (pas d'erreurs rouge)
```

## Étape 3 : Lancer l'application

```
1. Chercher "ChatConsoleApp" dans Project Explorer
2. Clic droit → Run 'ChatConsoleApp.main()'
3. Ou appuyer sur Shift + F10
```

## Étape 4 : Tester les GIFs

```
1. Sélectionnez un groupe de chat (à gauche)
2. Cliquez sur le bouton 🎁 (GIF)
3. Attendez que les GIFs se chargent (2-3 sec)
4. Cliquez sur un GIF pour voir l'aperçu à droite
5. Cliquez "Envoyer GIF"
6. Retournez au chat → Le GIF s'y affiche ! 🎬
```

## Troubleshooting rapide

| Problème | Solution |
|---|---|
| "Cannot resolve symbol 'GiphyService'" | Build → Rebuild Project |
| "Cannot resolve symbol 'org.json.JSONObject'" | Attendre Maven (bas de l'écran) |
| Les GIFs ne s'affichent pas | Vérifier internet, attendre 2-3 sec |
| "Erreur lors de l'envoi du GIF" | Vérifier logs (View → Tool Windows → Run) |
